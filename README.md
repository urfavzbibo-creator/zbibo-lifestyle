# 🧬 Zbibo Lifestyle

An automated lifestyle architecture application that balances work shifts, custom gym periodization, and recovery. 

## 🚀 Overview
Zbibo Lifestyle acts as a digital coach. It ingests the user's weekly work schedule and outputs a highly optimized daily routine that dictates strict sleep windows, strategic gym sessions (avoiding pre-work fatigue), and dedicated meal times.

## 🛠 Tech Stack
* **Frontend:** React.js
* **Backend / Database:** Firebase (User Auth & Real-time Schedule Storage)
* **Hosting:** Netlify (Continuous Deployment)
* **Styling:** Custom CSS (Dark Mode, Glassmorphism, Neon Accents)

## ⚙️ Core Engine Features
* **Smart Sleep Calculator:** Enforces recovery blocks based on work and gym intensity.
* **Fatigue Management:** Automatically schedules lighter conditioning or upper-body sessions prior to demanding work days, saving heavy lower-body days for off-days.
* **Automated Meal Routing:** Protects pre-workout and post-workout nutritional windows.
